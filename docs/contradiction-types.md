# Contradiction Types

## 목적

Trust404가 판매글에 작성된 거래 조건과 실제 채팅에서 판매자가 제시한 내용이
서로 달라지는 상황을 탐지할 수 있도록 모순 유형과 판단 기준을 정의한다.

단순한 표현 차이나 추가 설명을 모순으로 판단하지 않고,
가격, 거래 방식, 상품 상태 등 실제 거래 판단에 영향을 주는 핵심 정보가
서로 충돌하는 경우를 모순으로 판단한다.

---

## 판매글-채팅 모순 유형

| Contradiction Code | 분류 | 탐지 기준 | 판매글 예시 | 채팅 예시 |
|---|---|---|---|---|
| CONTRADICTION_PRICE | 가격 | 판매글의 상품 가격과 채팅에서 요구하는 실제 거래 금액이 다른 경우 | "판매가 300,000원" | "실제 거래는 350,000원입니다." |
| CONTRADICTION_LOCATION | 거래 장소 | 판매글에 안내된 거래 지역 또는 장소와 채팅에서 제시하는 장소가 다른 경우 | "서울 강남 직거래" | "지금은 부산이라 부산에서만 가능합니다." |
| CONTRADICTION_TRADE_METHOD | 택배/직거래 | 판매글에서는 직거래가 가능하다고 했으나 채팅에서는 택배만 가능하다고 하는 등 거래 방식이 변경된 경우 | "직거래 / 택배 모두 가능" | "직거래는 안 되고 택배만 가능합니다." |
| CONTRADICTION_PRODUCT_STATE | 상품 상태 | 판매글과 채팅에서 상품의 사용 여부, 개봉 여부, 파손 여부 등 상태 설명이 다른 경우 | "미개봉 새상품" | "상태 확인하려고 한 번 개봉했습니다." |
| CONTRADICTION_COMPONENTS | 구성품 | 판매글에 포함된다고 명시된 구성품이 채팅에서는 제외되거나 다르게 설명되는 경우 | "박스, 충전기 포함 풀박스" | "충전기는 없고 본체만 있습니다." |
| CONTRADICTION_PAYMENT | 결제 방식 | 판매글에서 안내한 결제 방식과 실제 채팅에서 요구하는 결제 방식이 다른 경우 | "안전결제 가능" | "안전결제는 안 하고 계좌이체만 받습니다." |
| CONTRADICTION_SELLER_DESCRIPTION | 판매자 설명 | 판매자가 판매글에서 설명한 상품 정보나 거래 조건을 채팅에서 다르게 설명하는 경우 | "직접 구매한 제품입니다." | "사실 지인에게 받은 제품이라 구매처는 모릅니다." |

## 분석 원칙

### 1. 단순한 추가 설명은 모순으로 판단하지 않는다

판매글:

> 아이폰 15 판매합니다.

채팅:

> 작년 12월에 구매했습니다.

판매글에 구매 시기가 없었기 때문에
새로운 정보가 추가된 것이며 모순으로 판단하지 않는다.

### 2. 의미가 실제로 충돌하는 경우만 탐지한다

판매글:

> 미개봉 제품입니다.

채팅:

> 상태 확인하려고 한 번 개봉했습니다.

상품의 개봉 여부가 서로 직접 충돌하므로
`CONTRADICTION_PRODUCT_STATE`로 탐지한다.

### 3. 거래에 영향을 주는 핵심 조건을 중심으로 판단한다

다음 정보를 주요 비교 대상으로 사용한다.

- 가격
- 거래 장소
- 거래 방식
- 상품 상태
- 구성품
- 결제 방식
- 판매자의 상품 및 거래 설명

### 4. 하나의 거래에서 여러 모순이 동시에 탐지될 수 있다

판매글:

> 30만원 / 직거래 가능 / 안전결제 가능

채팅:

> 35만원이고 택배만 가능합니다. 계좌이체만 받아요.

예상 탐지:

- CONTRADICTION_PRICE
- CONTRADICTION_TRADE_METHOD
- CONTRADICTION_PAYMENT

### 5. 모순의 근거를 함께 반환한다

탐지 결과에는 서로 충돌한 판매글 내용과 채팅 내용을 모두 포함한다.

  "contradictions": [
    {
      "code": "CONTRADICTION_TRADE_METHOD",
      "listingEvidence": "직거래 / 택배 모두 가능합니다.",
      "chatEvidence": "직거래는 안 되고 택배만 가능합니다.",
      "reason": "판매글에서는 직거래가 가능하다고 안내했으나 채팅에서는 직거래를 거부하고 택배 거래만 요구했습니다.",
      "relatedRisk": "RISK_CONDITION_CHANGE"
    }
  ],
  "summary": {
    "detectedCount": 1
  }
}
