# Problem Definition

기존 중고거래 사기 예방 서비스는 주로 전화번호나 계좌번호의 과거 신고 이력을 조회하는 방식에 의존한다.
하지만 신고 이력이 없다는 사실만으로 해당 판매자나 거래가 안전하다고 판단할 수는 없다.
특히 아직 신고되지 않은 신규 사기 계정이나 새로운 사기 수법은 기존 신고 이력만으로 사전에 탐지하기 어렵다.
Trust404는 판매글과 거래 과정에서 나타나는 의심 패턴, 거래 조건의 모순, 안전거래 정책과의 충돌 등 위험 신호를 분석하여 피해가 발생하기 전에 거래 위험을 탐지하는 것을 목표로 한다.
