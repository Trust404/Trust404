# Target User

## Primary Persona

중고거래 플랫폼을 이용하는 구매자 중,
판매자의 과거 신고 이력만으로 거래 안전성을 판단하기 어렵고
거래 전에 추가적인 위험 검증을 원하는 사용자.

특히 고가 상품이나 택배 거래 시
판매글과 채팅 내용을 기반으로 사기 위험을 미리 확인하고 싶은
20~30대 중고거래 이용자를 주요 대상으로 한다.

## 주요 사용 상황

1. 판매자가 안전결제를 거부하고 계좌이체를 요구할 때
2. 판매글의 내용과 채팅에서 제시하는 거래 조건이 달라졌을 때
3. 신고 이력은 없지만 입금 재촉, 외부 메신저 유도 등 수상한 행동이 있을 때

## Trust404 사용 시점

구매자가 판매자에게 돈을 보내기 전,
판매글·채팅·전화번호·계좌번호 등의 거래 정보를 입력하여
잠재적인 사기 위험 신호를 확인하는 단계에서 사용한다.
