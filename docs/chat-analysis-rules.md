# Chat Analysis Rules

## 목적

Trust404의 Conversation Analyzer가 판매자와 구매자의 채팅에서
거래 위험 신호를 일관된 기준으로 탐지할 수 있도록
채팅 분석 기준을 정의한다.

본 기준은 특정 표현 하나만으로 사기 여부를 확정하기 위한 것이 아니라,
채팅의 문맥과 반복 여부를 함께 고려하여
추가 확인이 필요한 거래 위험 신호를 탐지하기 위한 기준이다.

---

## 채팅 위험 패턴

| Risk Code | 위험 패턴 | 탐지 기준 | 예시 |
|---|---|---|---|
| RISK_PAYMENT_PRESSURE | 입금 압박 | 다른 구매자, 시간 제한 등을 이유로 빠른 입금을 반복적으로 요구 | "다른 분도 기다리고 있어서 지금 바로 입금하셔야 해요." |
| RISK_PAYMENT_REFUSAL | 안전결제 거부 | 구매자가 안전결제를 제안했으나 판매자가 특별한 이유 없이 거부하고 다른 결제 방법만 요구 | "안전결제는 안 하고 계좌이체만 받아요." |
| RISK_PREPAYMENT | 선입금 요구 | 상품 확인 또는 거래 확정 전에 예약금이나 전체 금액을 먼저 요구 | "예약하려면 먼저 5만원 보내주세요." |
| RISK_VERIFICATION_REFUSAL | 상품 인증 거부 | 추가 사진, 인증 사진, 영상 등 상품 보유 여부를 확인할 자료 제공을 거부 | "사진은 더 못 보내드려요. 그냥 믿고 거래하세요." |
| RISK_MEETUP_AVOIDANCE | 직거래 회피 | 직거래 가능 여부를 묻거나 제안했을 때 명확한 이유 없이 반복적으로 회피 | "직거래는 안 되고 무조건 택배만 됩니다." |
| RISK_EXTERNAL_MESSENGER | 외부 메신저 이동 | 플랫폼 내부 채팅 대신 카카오톡, 텔레그램 등 외부 채널로 이동하도록 유도 | "여기 말고 카톡으로 이야기하시죠." |
| RISK_CONDITION_CHANGE | 거래 조건 변경 | 가격, 배송, 결제 방식 등 이미 합의한 핵심 조건을 거래 도중 변경 | "직거래 가능하다고 했는데 지금은 택배만 됩니다." |
| RISK_URGENCY | 비정상적 긴급성 강조 | 합리적인 이유 없이 오늘만, 지금 즉시 등의 표현으로 빠른 결정을 강하게 유도 | "오늘 안에 입금하시면 이 가격에 드릴게요." |

## 분석 기준

### 1. 단순 키워드만으로 판단하지 않는다

예를 들어 판매자가 다음과 같이 말한 경우:

> "오늘은 시간이 없어서 내일 거래 가능해요."

`오늘`이라는 표현이 있다고 해서
RISK_URGENCY로 판단하지 않는다.

문장의 의미가 실제로 빠른 결제나 결정을 강요하는지 확인한다.

### 2. 대화 문맥을 함께 확인한다

같은 표현이라도 이전 대화와의 관계를 고려한다.

예:

구매자:
"안전결제로 하고 싶어요."

판매자:
"안전결제는 안 합니다. 지금 계좌이체하시면 바로 보내드릴게요."

이 경우 다음 위험 신호가 함께 탐지될 수 있다.

- RISK_PAYMENT_REFUSAL
- RISK_PAYMENT_PRESSURE

### 3. 하나의 채팅에서 여러 위험 신호를 탐지할 수 있다

위험 신호는 상호 배타적이지 않으며
동일한 문장 또는 대화에서 여러 패턴이 동시에 탐지될 수 있다.

### 4. 근거 문장을 반드시 반환한다

위험 신호를 탐지한 경우
판단의 근거가 된 실제 채팅 문장을 함께 반환한다.

예:

```json
{
  "risk_code": "RISK_PAYMENT_REFUSAL",
  "evidence": "안전결제는 안 하고 계좌이체만 받아요.",
  "reason": "구매자의 안전결제 제안을 거부하고 계좌이체만 요구함"
}
